# 黑板樹 Blackboard Tree

免費的教室投影白板（1.6.0 以前叫 **MyScreen**）。白板存在老師自己的**網路磁碟機（V:）**，換電腦、換教室都能接著用。

> **下載與安裝**：請看 [RELEASE.md](RELEASE.md)（要下載哪個檔案、安裝步驟、升級注意事項、版本紀錄）

## 功能

| 類別 | 小工具 |
|---|---|
| 時間 | 計時器（時間到會閃爍、響鈴）、時鐘日期（時間可選數字／指針／不顯示，日期可選一行文字／月曆，可用民國年）、碼錶（可分段） |
| 班級經營 | 隨機抽籤（不重複）、隨機分組、座位表（隨機排座、點兩下交換、隨機點名）、課堂加分（學生卡片加減分）、工作模式、音量計（麥克風）、投票（可讓學生用手機掃 QR Code 投票） |
| 內容 | 文字、畫板、圖片（可選個人資料夾裡的圖片）、QR Code、網頁／影片（YouTube、Facebook、Instagram、Threads、TikTok、Vimeo、影片檔、Google 簡報）、視訊鏡頭 |

- 可以建立多個白板（例如每個班一個），開啟時先從清單選擇要用哪一個
- 背景可選漸層、純色、格線，或用個人資料夾裡的圖片
- **班級名單**：按上方「👥 名單」匯入學生名單與照片，存一次，所有白板與裝置都能使用（見下方說明）
- **⚙ 設定**（上方工具列）：集中管理
  - 白板：切換、新增、重新命名、複製、刪除、背景
  - 班級名單：查看各班人數，進入名單管理
  - 工具列：放在畫面上／下／左／右、工具大小（迷你／小／中／大／特大）、工具列文字（自動／顯示／隱藏；自動：視窗較小時只顯示圖示，適合解析度較低的筆電、投影機）、要顯示哪些工具（不常用的可以隱藏，手機遙控的「加入小工具」也會跟著隱藏）
  - 這些設定存在老師的 `V:\MyScreen\settings.json`，換電腦也會套用
  - 關於與更新：顯示目前版本、檢查 GitHub 上的新版本與更新內容，按「下載並更新」就會自動下載、安裝並重新開啟（見下方「更新到新版」）
- 計時器、碼錶記錄的是「絕對時間」，換台電腦打開，倒數時間一樣是對的
- **小工具放大到全螢幕**：按小工具右上角的 ⛶（或雙擊標題列），小工具會填滿整個畫面並切換到全螢幕，內容自動放大；按 🗗 或 `Esc` 還原。手機遙控的每張卡片也有「⛶ 放大」按鈕
- 快捷鍵：`H` 隱藏工具列，`F` 全螢幕，`Esc` 還原放大的小工具

## 👥 班級名單與學生照片

按上方「👥 名單」→「＋ 新增班級」，然後：

- **📥 匯入名單（Excel／CSV）**：支援 .xlsx、.xls、.csv、.txt，台灣版 Excel 存的 Big5 編碼 CSV 也能讀。選好檔案後會出現「選擇匯入欄位」畫面：
  - 系統會自動判斷標題列（學校報表第一列常是「○○學年度 ○年○班」，會自動跳過）與欄位：**座號、姓名、學號**
  - 欄位很多也沒關係（班級、性別、身分證、家長姓名、電話…），只會匯入這三項；家長姓名不會被當成學生姓名
  - 老師可以在畫面上確認預覽，或自己選擇每個項目對應檔案的哪一欄
- **📋 貼上名單**：從 Excel 複製後貼上（有多欄時同樣會出現選擇欄位畫面），或每行一個名字
- **🖼️ 匯入照片**：一次選全班的照片，依檔名自動對應，順序是：
  1. **學號**（優先）：檔名中有學號就行，例如 `1130101.jpg`、`1130101_王小明.jpg`、`IMG_1130101.jpg`、`S1130101.png`
  2. **姓名**：`王小明.jpg`、`01王小明.jpg`
  3. **座號**：檔名只有數字時，例如 `01.jpg`、`1.jpg`

  對應不到的會列出檔名；照片檔名是學號但名單沒有學號時會提醒。也可以點單一學生的照片格更換
- 每位學生有座號、學號、姓名，都可以直接在名單上修改；重新匯入名單時，照片會依學號（或姓名）保留
- 照片會自動縮小（約 270×360）存在 `V:\MyScreen\media`，名單存在 `settings.json`

**隨機抽籤、分組、座位表、課堂加分**都直接讀取班級名單（這些教學用的小工具只顯示座號、姓名、照片，不顯示學號）：

- 新加入的小工具會自動使用上次用過的班級，也可以在 ⚙ 設定的「名單來源」切換班級，或改成自己輸入
- 抽到的同學會顯示照片，座位表、分組也會顯示大頭照（可在設定關閉）；手機遙控也看得到被抽中同學的照片
- 在「👥 名單」新增、刪除或改名學生後，白板上的小工具會自動更新，座位位置不變

### ⭐ 課堂加分

每位學生一張卡片：右上角座號、照片（沒有照片時顯示預設頭像）、姓名、左上角目前分數，下方紅色「−」、綠色「＋」按鈕。

- 加減分時卡片會閃一下並跳出「+1」，可在設定關閉音效
- 上方有「全班 +1」「全班 −1」「歸零」與全班總分
- 卡片大小會依小工具大小自動調整，全班盡量一次放得下
- 設定可選「依座號」或「依分數（高分在前）」排列
- 手機遙控會列出全班，可以直接幫每位學生加減分

## 使用流程

1. 先用學校的「網路磁碟機」程式登入，把個人資料夾連到 **V:**
2. 開啟黑板樹 → 自動讀取 `V:\MyScreen`（第一次使用時會自動建立）
3. 從清單選擇白板，或新增一個

第一次開啟時，可以選擇白板要存在哪裡，之後會記住並自動讀取：

| 儲存位置 | 說明 |
|---|---|
| 📁 網路磁碟機或資料夾 | **建議使用**。存在 `V:\MyScreen`，任何連上 V: 的電腦都能讀取；也可以「選擇其他資料夾」，例如隨身碟或雲端硬碟同步資料夾 |
| 💻 只存在這台電腦 | 不同步，適合臨時使用 |

桌面版和網頁版讀寫的是同一種資料夾格式：選同一個資料夾，就會看到同樣的白板。

### 資料夾內容

```
V:\MyScreen\
  ├─ boards\<代碼>.json     每個白板一個檔案
  ├─ settings.json          班級名單
  └─ media\                 加入的圖片
```

V: 暫時斷線時，白板仍可繼續使用（先存在這台電腦），連線恢復後會自動補存。兩台電腦同時修改同一個白板時，較晚存檔的那台會收到提示，並載入最新版本。

## 兩種執行方式

### A. 桌面版（建議）

和「網路磁碟機」程式一樣，是一個 Windows 程式（Neutralino）。開啟後直接讀寫 V:，**不需要架設伺服器，也不需要 HTTPS**。

- V: 還沒連線時，請先用學校的網路磁碟機程式連線，再按「重新檢查」；也可以按「選擇其他資料夾」改存到別的地方
- 預設的磁碟機代號（V:）可在 `desktop/neutralino.config.json` 的 `globalVariables.MSROOT` 修改

#### 安裝

執行 `BlackboardTree-Setup-1.6.1.exe`，依畫面按「下一步」即可：

- 安裝到 `%LOCALAPPDATA%\Programs\BlackboardTree`（從 1.5 以前升級的電腦沿用原本的 `%LOCALAPPDATA%\Programs\MyScreen`），**不需要系統管理員權限**（和網路磁碟機程式相同）
- 會建立開始功能表與桌面捷徑，並出現在「設定 → 應用程式」中，可以從那裡解除安裝
- 安裝新版時會自動關閉正在執行的黑板樹；解除安裝不會刪除 `V:\MyScreen` 裡的白板
- 這台電腦上的設定與離線備份（遙控代碼、V: 斷線時的白板備份等）存在 `%APPDATA%\MyScreen\prefs.json`

#### 更新到新版

1.5.0 起，「⚙ 設定 → ℹ 關於與更新」會檢查 GitHub 上有沒有新版本（開啟黑板樹時也會自動檢查，一天一次；有新版本時「⚙ 設定」按鈕會出現小紅點）：

- 按「下載並更新」：下載後比對檢查碼，黑板樹存檔並關閉，更新完成後自動重新開啟
- 安裝版：下載新的安裝程式靜默安裝；裝在 Program Files（`/ALLUSERS`）時會要求系統管理員權限
- 免安裝版：直接換掉原本的 `BlackboardTree.exe`（所在資料夾要能寫入）
- 需要連到 `raw.githubusercontent.com`；版本資訊來自 `desktop/out/latest.json`（建置時產生）

資訊組大量部署時可以用靜默安裝：

```
BlackboardTree-Setup-1.6.1.exe /VERYSILENT /SUPPRESSMSGBOXES /TASKS=desktopicon
```

手機遙控與學生投票由老師的電腦擔任伺服器，安裝時不需要設定。

要為電腦上所有使用者安裝（裝到 Program Files），請以系統管理員執行並加上 `/ALLUSERS`。不想安裝的話，也可以直接使用免安裝版 `BlackboardTree.exe`。

#### 建置

需要 Node.js（第一次建置需要網路下載 Neutralino 與 `resedit`）；要產生安裝程式還需要 [Inno Setup 6](https://jrsoftware.org/isdl.php)：

```
cd desktop
powershell -ExecutionPolicy Bypass -File build.ps1
```

產出在 `desktop\out\`：

| 檔案 | 說明 |
|---|---|
| `BlackboardTree-Setup-<版本>.exe` | 安裝程式（找不到 Inno Setup 時不會產生） |
| `BlackboardTree.exe` | 免安裝版，單一檔案（已內含手機遙控伺服器），複製到電腦即可執行 |

版本號碼在 `desktop/neutralino.config.json` 的 `version`；安裝程式設定在 `desktop/installer/setup.iss`。

### B. 網頁版

用 **Edge 或 Chrome** 開啟，選擇「網路磁碟機或資料夾」→ 選 V: 磁碟機（或 V: 裡的 MyScreen 資料夾）→ 瀏覽器詢問時選「允許」。之後開啟會自動讀取；部分瀏覽器版本每次開啟需要再按一次「繼續使用」。

有兩種放法：

- **用黑板樹伺服器開啟（可以手機遙控、學生投票）**：在一台電腦上執行 `start.bat`（Linux 執行 `sh start.sh`，第一次會自動安裝相依套件，需要 Python 3.10 以上），再開啟 `http://localhost:8080`。伺服器只提供網頁與手機遙控的轉送，**白板不會存在伺服器上**
- **只放網頁**：把 `static/` 資料夾放到任何網頁伺服器上即可，但沒有手機遙控與學生投票

> 瀏覽器只允許 `https://` 或 `localhost` 網址存取資料夾。若用 `http://192.168.x.x` 開啟，將無法使用資料夾模式（麥克風、鏡頭也無法使用），需要開啟 HTTPS。

伺服器設定（選用）：複製 `config.example.json` 為 `config.json`，可以修改 `host`、`port`（預設 8080）與 HTTPS 憑證。

#### 開啟 HTTPS

1. 使用 [mkcert](https://github.com/FiloSottile/mkcert) 產生憑證，並在各台電腦安裝根憑證：`mkcert -install`、`mkcert 192.168.1.20`
2. 在 `config.json` 填入 `"ssl_certfile": "192.168.1.20.pem"`、`"ssl_keyfile": "192.168.1.20-key.pem"`

## 📊 學生用手機投票

1. 在白板加入「投票」，按 ⚙ 設定題目與選項
2. 按投票小工具下方的「📱 學生投票」：小工具會放大並顯示 QR Code
3. 學生用手機掃描 QR Code（或開啟下方網址），輸入名字（或座號），點選答案即可，不需要帳號
4. 按「■ 結束投票」：學生的頁面顯示「投票已結束」，白板顯示結果

- 同一個名字只算一票；可在設定選擇是否「允許學生改票」
- 預設投票時隱藏票數，結束後才顯示（避免從眾），可在設定關閉
- 投票中可以修改題目，學生的手機會立即更新
- 設定畫面會列出已投票的名字，方便確認還有誰沒投
- 學生拿到的是**另一組投票代碼**，只能投票，不能遙控白板
- 學生的手機要和老師的電腦在同一個校內網路（與手機遙控相同）。網頁版用 `http://localhost` 開啟時，QR Code 會自動改用伺服器的校內 IP；電腦有多個 IP 時，可在「📱 遙控」視窗切換；按「歸零」會清除票數與投票紀錄

### 📚 題庫與投票紀錄

投票小工具下方的「📚 題庫」，或「⚙ 設定 → 📊 投票」：

- **題庫**：把目前的題目存起來，下次按「使用這題」就能再問一次（在設定畫面按「加到白板」會新增一個投票小工具）
- **匯入題目**：一次加入多題，可以貼上文字或選擇 Excel／CSV／文字檔
  - 文字：每題一段，第一行是題目，下面每行一個選項，題目之間空一行
  - Excel／CSV：每列一題，第一欄是題目，後面每欄一個選項（第一列可以是「題目、選項1、選項2…」標題）
- **投票紀錄**：結束學生投票、按「歸零」或換題目時，會自動記錄當時的結果（包含每位學生投給哪一項）；手動點票的投票也可以按「記錄目前結果」
- **匯出**：投票紀錄可以匯出成 CSV，用 Excel 直接開啟（每個選項一列：日期、白板、題目、選項、票數、百分比、投票學生）
- 題庫與紀錄存在老師的 `V:\MyScreen\settings.json`，換電腦也能用；紀錄最多保留最近 500 筆

## 📱 手機／平板遙控

老師在教室電腦（接大電視）開啟黑板樹後，可以用手機或平板遙控：

1. 按上方的「📱 遙控」，電視上會顯示 QR Code 和 6 位數代碼
2. 手機掃描 QR Code（或開啟網址後輸入代碼），不需要安裝 App
3. 手機上會依白板內容列出按鈕：計時器開始／暫停／加減時間、抽籤、分組、座位表（交換座位、隨機點名）、工作模式、投票、從手機打字到文字框，也可以切換白板、加入或移除小工具、隱藏工具列、全螢幕
4. **傳送網址**：在手機最上方貼上網址（或按「📋 貼上並開啟」），就會送到教室電腦：
   - YouTube 或影片檔（.mp4、.webm 等）→ 在白板上放大播放，手機可以播放／暫停、靜音、從頭播放；再傳新的影片會取代上一部
   - Facebook（影片、Reels、貼文）、Instagram（貼文、Reels）、Threads、TikTok、Vimeo → 用官方嵌入方式顯示在白板上，直式短影音會放成直的。這些網站不開放外部控制，請在電視上點播放；非公開貼文無法嵌入，可在手機上按「改用瀏覽器開啟」
   - 其他網址 → 在教室電腦用預設瀏覽器開啟（網頁版因瀏覽器限制，會在畫面上顯示「點這裡開啟」）

安全設計：

- 代碼是隨機產生的，錯誤代碼嘗試太多次會暫時封鎖
- 按「中斷全部並換代碼」會立刻踢掉所有遙控裝置，舊代碼隨即失效
- 每個白板最多 8 台裝置同時連線
- 遙控伺服器只負責轉送指令，不保存任何資料，白板仍然存在老師的 V:

### 老師的電腦就是遙控伺服器

桌面版內建遙控伺服器（`myscreen-relay.exe`，約 64 KB），安裝版與免安裝版都已經包含：

- **安裝版**：安裝在程式資料夾（防火牆例外也是指定這個位置）
- **免安裝版**：內嵌在 `BlackboardTree.exe` 裡，仍然是單一檔案；第一次執行時自動解出到旁邊，換新版時自動更新

**開啟黑板樹時伺服器就一起啟動**，按「📱 遙控」會直接顯示 QR Code，並自動帶入這台電腦的校內 IP（例如 `http://192.168.0.99:52480`），手機連上校內網路掃描即可，**不需要另外架設伺服器**。

- **右下角系統匣**有黑板樹圖示（Windows 11 可能收在「^」裡，可拖到工作列上常駐顯示），按一下可以看到：
  - 遙控伺服器狀態與網址（例如「執行中（192.168.0.99:52480）」）、目前有幾台手機連線
  - 「手機遙控（顯示 QR Code）」：把黑板樹叫到前面並顯示 QR Code
  - 「結束黑板樹」：存檔後關閉程式與遙控伺服器
- 關閉黑板樹時伺服器會一起關閉；黑板樹異常結束時，伺服器也會在幾秒內自動結束
- 重新開啟黑板樹時會沿用原本的代碼，已經連過的手機會自動重新連上，不用重新掃描
- 電腦有多個網路位址（例如同時接有線、無線）時，遙控畫面可以切換 QR Code 使用的位址
- 網路變動（換 Wi-Fi、插拔網路線）後會在幾秒內重新偵測 IP，QR Code 自動改用新的網址
- 連接埠預設 52480，被占用時自動改用下一個
- 用 Windows 內建的 .NET Framework 4 執行，不需要另外安裝任何東西

**Windows 防火牆**：手機要連進這台電腦，需要防火牆允許 `myscreen-relay.exe`。

- 安裝時勾選「允許手機連線到這台電腦」（預設勾選）：以系統管理員安裝時直接加入；一般帳號安裝會跳出系統管理員確認，可請資訊組輸入密碼
- 大量部署建議以系統管理員執行：`BlackboardTree-Setup-1.6.1.exe /VERYSILENT /ALLUSERS /TASKS="desktopicon,firewall"`
- 沒有加入例外時，第一次開啟遙控 Windows 會詢問是否允許，需要系統管理員權限才能允許

> **網路注意事項**：手機必須能連到教室電腦（同一個校內網路）。若學校的無線網路（手機）和教學網路（教室電腦）是分開的網段，請資訊組開放手機網段連到教室電腦的 52480 埠（網頁版是 8080 埠）。

## 檔案結構

> 要接手開發或在其他電腦繼續開發，請看 [DEVELOPMENT.md](DEVELOPMENT.md)（開發環境、建置、架構、注意事項、待辦）。

```
static/                  前端（原生 JavaScript，不需要編譯）
  js/app.js              主程式：選擇儲存位置、白板清單、拖曳、工具列
  js/store.js            存檔、離線暫存、跨裝置同步
  js/roster.js           班級名單：匯入 Excel／CSV、學生照片
  js/backends/index.js   兩種儲存方式（資料夾／本機）
  js/backends/fs.js      資料夾存取：瀏覽器（File System Access）與桌面版（Neutralino）
  js/widgets/            各個小工具
static/remote.html       手機遙控頁（js/remote.js）
static/vote.html         學生投票頁（單一檔案）
static/js/remote-host.js 教室電腦端的遙控連線
desktop/relay/           內建遙控伺服器（C#，Windows 內建 .NET Framework 編譯）
desktop/installer/       安裝程式（Inno Setup）
desktop/                 桌面版設定與建置腳本
server/app.py            網頁版伺服器（FastAPI）：提供網頁與手機遙控轉送
server/relay.py          手機遙控、學生投票轉送（WebSocket）
start.bat, start.sh      啟動網頁版伺服器
```

新增小工具：在 `static/js/widgets/` 中新增一個物件 `{ type, title, icon, size, state(), mount(body, ctx) }`，並加入 `widgets/index.js` 的清單。若要支援遙控，讓 `mount` 回傳 `remote: { view(), act(action, args) }`，並在 `static/js/remote.js` 的 `RENDER` 加上手機畫面。
